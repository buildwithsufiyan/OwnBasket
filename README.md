## About OwnBasket

OwnBasket is a modern Django-powered e-commerce platform designed with a dynamic theme engine, visual homepage builder, responsive layouts, product management, shopping cart, checkout and order management features.

## ✨ Main Features

- Dynamic Theme Engine
- Visual Homepage Builder
- Responsive E-Commerce Layouts
- Product and Category Management
- Product Carousel System
- Shopping Cart and Checkout
- Order Management System
- Django Admin Controls
- Modular and Scalable Architecture
