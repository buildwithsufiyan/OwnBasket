# OwnBasket

OwnBasket is a modern Django-based e-commerce platform developed by Md Sufiyan Hussain under QentraX.

## Overview

OwnBasket is built to provide a clean and professional online shopping experience. It includes product browsing, cart, wishlist, checkout flow, admin product management, and responsive UI sections.

## Key Features

- Modern responsive homepage
- Product carousel system
- Product listing page
- Product detail page
- Cart functionality
- Wishlist functionality
- User authentication
- Checkout and order flow
- Admin-managed products and banners
- Discount and featured product controls

## Tech Stack

- Python
- Django
- HTML
- CSS
- JavaScript
- Bootstrap
- SQLite
